# Storage Client Redesign

Минимальная переработанная копия клиента склада. Сейчас в проект перенесены только:

- OIDC-вход через системный браузер;
- проверка пользователя через `api/Auth/me`;
- настройка адреса API с безопасным перезапуском;
- светлая и тёмная темы MDIX + MahApps;
- стартовый макет окна авторизации;
- временное системное подтверждение успешной авторизации вместо главного окна.

Складские таблицы, корзины, документы, администрирование, импорт и прочие большие модули намеренно не переносились.
